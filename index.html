A unionized company, run by a working carpenter

Get It Right Renovations Inc. is owned and run by Matthew Martin, a Local 27 carpenter. The company is a signatory to Local 27, so the work on your home is done by a unionized company with union craftsmanship behind it — clean sites, clear timelines, and work done right the first time.

Professional • Efficient • Clean — that's the standard on every job, from a single bathroom to a full home renovation.
